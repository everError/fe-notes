# ledger — 달통장

한 달 동안 쓸 돈을 정해 두고, 지출·입금·저축을 달력에 기록하며 남은 돈을 줄여 가는 개인 가계부.
SvelteKit, Svelte 5, TypeScript, Tailwind CSS 4, Node 내장 SQLite(`node:sqlite`)로 만들었다.

## 개발 서버

```sh
npm install
npm run dev        # http://localhost:5173/
```

검증:

```sh
npm run check      # svelte-check
npm run lint       # prettier + eslint
npm run build
```

## 화면

| 경로        | 내용                                                                                                 |
| ----------- | ---------------------------------------------------------------------------------------------------- |
| `/`         | 가계부 — 남은 돈·입금·지출 요약, 월 저축 진행, 달력, 선택한 날의 기록 입력·수정·삭제                 |
| `/insights` | 분석 — 하루 평균·월말 예상 잔액, 남은 돈 변화 그래프, 분류별·결제수단별 지출, 저축 목표 진행·월 목표 |
| `/manage`   | 관리 — 고정지출, 분류, 결제수단, 저축 목표 CRUD, 예시 데이터로 되돌리기                              |

모든 화면은 주소의 `?m=YYYY-MM` 으로 기준 달을 공유한다(`+layout.server.ts`). 가계부 화면은 `&d=일` 로 선택한 날을 갖는다.
데스크톱은 왼쪽 사이드바, 모바일은 하단 탭으로 이동한다.

## 기록 종류

| 종류     | 분류                                                          | 추가 필드           |
| -------- | ------------------------------------------------------------- | ------------------- |
| `spend`  | 지출 분류(기본: 식비·교통·카페·쇼핑·문화·생활·통신·구독·기타) | 결제수단(카드/통장) |
| `income` | 입금 분류(기본: 월급·용돈·환급·중고판매·기타입금)             | —                   |
| `save`   | 고정 "저축"                                                   | 저축 목표           |

남은 돈 = 시작금액 + 입금 − 지출 − 저축. 저축은 통장에서 빠져나간 것으로 보아 남은 돈에서 차감하고, 별도 합계로도 집계한다.
오늘 이후 날짜에는 기록할 수 없다.

## 데이터베이스

- `data/ledger.db` 를 사용한다(경로는 `LEDGER_DB` 환경변수로 바꿀 수 있다). 요청이 처음 들어올 때 자동 생성·시드된다.
- dev 서버가 DB 파일을 잡고 있으므로 서버가 도는 동안에는 다른 도구로 열 수 없다.

| 테이블            | 내용                                                                         |
| ----------------- | ---------------------------------------------------------------------------- |
| `month_start`     | 월별 시작금액                                                                |
| `entries`         | 내역(종류, 금액, 분류, 결제수단, 저축 목표, 출처 `manual` 또는 `fixed:<id>`) |
| `fixed_defs`      | 고정지출 정의(이름, 매월 지정일, 금액, 분류)                                 |
| `fixed_log`       | 고정지출이 특정 달에 기록됐다는 로그                                         |
| `categories`      | 지출·입금 분류(기본 분류 포함)                                               |
| `payment_methods` | 카드·통장                                                                    |
| `savings_goals`   | 저축 목표(이름, 목표액, 목표 달)                                             |
| `month_save_goal` | 월 저축 목표                                                                 |

## 코드 구조

| 파일                                     | 역할                                                                      |
| ---------------------------------------- | ------------------------------------------------------------------------- |
| `src/routes/+layout.svelte`              | 사이드바·하단 탭·월 이동                                                  |
| `src/routes/+page.svelte` / `.server.ts` | 가계부 화면 / `add` `update` `delete` `setStart` `recordAllFixed`         |
| `src/routes/insights/`                   | 분석 화면 / `setSaveGoal`                                                 |
| `src/routes/manage/`                     | 관리 화면 / 고정지출·분류·결제수단·저축 목표 액션, `reset`                |

| `src/lib/server/validate.ts`             | 폼 입력 검증 공통 함수                                                    |
| `src/lib/components/`                    | `Icon`, `BalanceChart`                                                    |
| `src/lib/format.ts`, `categories.ts`     | 날짜·금액 포맷, 기본 분류·색 정의                                         |
| `src/routes/layout.css`                  | 디자인 토큰(`--color-brand` 등)과 공용 클래스(`.card` `.btn` `.input` 등) |
